# 課堂教學指引（老師版）

給在課堂上使用本工具的老師。工具本身只是載體，真正要傳遞的是**背單字的方法論**——所以建議先講心法，再讓學生動手。

---

## 課前準備

| 項目 | 說明 |
|---|---|
| 裝置 | 學生自備筆電或手機皆可（介面已做響應式）；投影用電腦一台 |
| 瀏覽器 | **建議 Chrome 或 Edge**。跟讀評分功能 Firefox 不支援 |
| 網路 | 首次載入需要網路（CDN 與資料檔），之後操作不需要 |
| 麥克風 | 要做跟讀活動的話，請學生先允許麥克風權限 |
| 事前測試 | 開場前先自己跑一輪，確認網路環境沒有擋掉 CDN |

> 投影提醒：工具的字級與對比已針對教室投影調大，但**背面卡片展開練習面板後會變長**，投影時建議先收合練習面板再講解。

## 45 分鐘課堂教案

### 第 1 段｜為什麼你背的單字都忘了（8 分鐘）

**投影**：點右上角 🔗 打開「多語學習三大核心策略」心智圖。

先不要介紹工具。先問學生兩個問題：

1. 「你背過的單字，現在還記得幾成？」
2. 「你背單字的時候，是先看英文還是先看中文？」

接著用心智圖講三個關鍵概念（不用講完 12 條，挑這三條就好）：

- **九秒記憶法** —— 記憶靠的是重複的頻率，不是單次背很久。所以複習排程比努力程度重要。
- **建立外語腦** —— 你如果每次都先看到中文，大腦就永遠在做翻譯，而不是在用英文思考。
- **語言組塊** —— 母語者說話是把「積木」拼起來，不是逐字造句。記 chunk 才能開口。

### 第 2 段｜示範一輪（7 分鐘）

投影操作，刻意示範這幾件事：

1. 翻開一張卡，**指著模糊的中文**說：「先別看，你先用英文例句猜。」
2. 按下 Good，**指著按鈕下方的「明天」**：「這不是打分數，是在跟系統約下次見面的時間。」
3. 打開語言積木區，朗讀一次 chunk：「這一整組要一起記，不要拆開。」
4. 打開 🎤 跟讀評分，當場念一次給全班看機器判定的結果——**故意念錯一次**效果更好。

### 第 3 段｜學生實作（20 分鐘）

讓學生打開工具，設定程度後開始練習。建議指定任務：

> 「完成 20 張，其中至少 5 張要用 🎤 跟讀評分念到合格，並且至少 3 張要寫造句。」

巡堂時重點看兩件事：
- 有沒有人**每張都按 Easy** —— 這代表沒在誠實評分，排程會失效
- 有沒有人**沒開外語腦模式** —— 提醒打開 🧠

### 第 4 段｜AI 協作示範（10 分鐘）

這段是 AI 時代的重點。挑一位學生的造句，投影示範：

1. 在 🤖 AI 提示分頁按「複製提示詞」
2. 貼到 ChatGPT / Claude
3. 讓全班看 AI 如何**先指出結構問題再改寫**，而不是直接翻譯

**要強調的觀念**：AI 不是拿來查單字的（那是字典），AI 的價值在於**幫你把「中文思維的英文」改成「英文思維的英文」**，並且告訴你為什麼。學生要學會的是問對問題，不是要答案。

## 分組活動建議

### 活動 A：機器聽得懂嗎（10 分鐘，兩人一組）
兩人輪流用 🎤 跟讀評分念單字，互相記錄對方幾次才通過。討論：哪些音最容易被機器聽錯？（通常是字尾子音、th、l/r）

### 活動 B：積木造句賽（15 分鐘，四人一組）
每組抽 5 個單字，只准使用卡片上的「語言積木」拼出一段對話，不准自己造新結構。比哪一組最像母語者說話。
→ 對應原則「區塊建築原則：直接搬用母語者的積木」。

### 活動 C：意象接力（10 分鐘，全班）
投影一個單字，每位學生說出一個具體畫面（不准說中文翻譯），比誰的畫面最好記。
→ 對應原則「核心意象」。

## 常見狀況與處理

| 狀況 | 原因與處理 |
|---|---|
| 學生說「麥克風沒反應」 | 瀏覽器權限被拒。請在網址列左側點鎖頭圖示重新允許；或改用 Chrome |
| Firefox 用戶按跟讀沒作用 | Firefox 不支援語音辨識，介面會顯示提示。請改用 Chrome / Edge |
| 「待複習：0 字」 | 正常。新字按 Good 要隔天才到期。請學生繼續學新字 |
| 學生進度互相蓋掉 | 共用電腦時紀錄會混在一起。共用機請當「當下練習」用，別依賴長期進度 |
| 卡片載入停在「請上傳 CSV」 | 用檔案總管直接雙擊開啟 HTML 會被 CORS 擋住。請用網址開啟，或手動上傳 CSV |
| 投影字太小 | 瀏覽器按 `Ctrl` + `+` 放大；工具本身版面會自動適應 |

## 評量建議

工具本身**不會產生成績報表**（沒有後端、不收集資料），所以評量請用學生的產出，而不是工具的數字：

- **造句品質** —— 請學生把 AI 批改前後的句子貼到作業，重點看他從 AI 的回饋學到什麼
- **跟讀通過數** —— 請學生截圖合格畫面
- **意象筆記** —— 檢查是不是寫成「具體畫面」而不是抄中文翻譯

> 提醒：學生的連續天數 🔥 與完成張數存在他自己的瀏覽器，老師端看不到，也無法驗證，不建議直接拿來計分。

## 延伸：換成自己的單字表

工具支援上傳自訂 CSV，你可以把課本單元的單字整理成同樣欄位後上傳，整套學習機制（間隔重複、外語腦、跟讀評分）都能直接套用。欄位格式見 [README](../README.md#自訂單字資料)。
