# 競品分析

> 查證日期：2026-08-23。價格與功能會變動，引用前請自行複查。

這份文件誠實記錄一件事：**本工具的每一項功能，市場上都已經有人做過，而且大多做得比我們好。**

之所以還值得做，是因為差異不在功能，在定位。以下是完整比較。

---

## 一、逐項功能比較

## 二、單字量不是賣點

本工具收錄 9,782 字，但這**不應該當作行銷重點**，理由：

- 市場上受歡迎的是「600 高頻字」這類**精選路線**，因為多數學習者根本背不完一萬字。
- 字多反而增加選擇焦慮。本工具用「難度等級 + 星級排序 + 略高一階選材」來緩解，但這是補救，不是優勢。
- 真正影響成效的是**複習排程與輸出練習**，不是題庫大小。

> 對外描述請避免主打「近萬字」，改為主打方法論與課堂適用性。

## 三、我們真正的差異

扣掉功能競賽之後，剩下四點是競品沒有的。

### 1. 這是「可以拿來教」的工具，不只是拿來用的工具
所有競品都在賣「幫你背單字」，**沒有一個內建方法論投影面板**。本工具點一下即可對全班展示「語言學習方法架構」12 條原則，並當場指出每條原則對應介面上的哪個按鈕。

工具與教材合體，這是本專案最不可取代的部分。

### 2. AI 提示詞是「看得見的」——這是 AI 素養教學
競品把 AI 藏在按鈕後面：學生按一下得到答案，但學不到怎麼問。

本工具刻意把提示詞攤開、可複製、可修改，學生會看到「原來要這樣要求 AI 先改結構再翻譯，而不是叫它直接翻譯」。

**競品在教英文；本工具順便在教怎麼用 AI。**

### 3. 課堂零摩擦
| competitor | 學生要做什麼才能開始 |
|---|---|
| Anki | 安裝軟體 → 找／匯入牌組 → 設定 |
| Quizlet | 註冊帳號 →（間隔重複要付費） |
| ELSA Speak | 註冊 → 訂閱 |
| **本工具** | **打開網址** |

沒有帳號、沒有個資蒐集、沒有採購流程、沒有 API 金鑰。對帶班的老師而言，這是**行政上的實際優勢**，而非技術優勢。

### 4. 老師可以換成自己的教材
單一 HTML 檔 + MIT 授權 + 可替換 CSV。任何老師都能把自己課本單元的單字換進去，整套機制（間隔重複、外語腦模式、語言積木、跟讀評分、AI 提示）立即沿用。

**它是一個教學範本，不是一個封閉產品。**

## 四、刻意的取捨（不是還沒做）

| 取捨 | 為什麼 |
|---|---|
| AI 用「產生提示詞」而非串接 API | 純前端無後端可安全保管金鑰；且提示詞外顯本身就有教學價值 |
| 用 SM-2 精簡版而非 FSRS | FSRS 需要較多實作與參數最佳化；現階段目標是讓學習者**理解**排程邏輯（按鈕上直接顯示間隔），而非追求演算法極致 |
| localStorage 而非雲端帳號 | 保住「打開網址就能用」與零隱私疑慮；代價是不同步，已於文件明示 |
| 不做成績報表 | 無後端就無法可信驗證數據，與其做一個可隨意造假的報表，不如明說沒有 |

## 五、定位結論

**不要跟 Anki 比演算法，也不要跟 ELSA 比發音診斷——那兩場仗必輸。**

> ### 定位
> 一個可以帶進教室講解的**語言學習方法論示範品**，
> 順便是一套堪用的日常與商務英語單字卡。

| | 適合 | 不適合 |
|---|---|---|
| **對象** | 老師（課堂教學、方法論示範）、想理解「為什麼這樣背」的自學者 | 只想要最強排程演算法的重度使用者 |
| **情境** | 課堂投影、工作坊、教學示範、想改成自己教材的人 | 需要跨裝置同步、長期個人化追蹤 |
| **替代建議** | — | 追求極致效率請用 **Anki（FSRS）**；追求發音精準診斷請用 **ELSA Speak** |

誠實說出「什麼時候該用別的工具」，比宣稱樣樣都強更能建立信任——這也是開源專案該有的態度。

## 六、未來若要補強，優先順序

1. **精選字表**（如「日常 600 高頻」子集）——比擴充字數有價值得多
2. **匯出到 Anki**（`.apkg` 或 CSV）——承認 Anki 排程更強，讓使用者能無痛升級，反而增加本工具作為「入門與教學」的價值
3. **FSRS 排程**——若要認真做長期學習者市場
4. 跨裝置同步——需引入後端，會改變「零帳號」定位，須審慎評估
