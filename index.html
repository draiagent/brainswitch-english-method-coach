外語腦單字卡 使用說明

三步驟開始：① 點 設定你的程度 → ② 點卡片翻面看解析 → ③ 依熟悉度按 Again / Hard / Good / Easy，系統會安排這個字下次何時再出現。

1. 互動方式：

  • 點擊正面卡片或按 空白鍵 / Enter 翻開背面。
  • 點擊 🔊 聆聽單字、語言積木或例句（瀏覽器內建語音）。
  • 背面點 Again / Hard / Good / Easy，決定這個字下次何時再出現（間隔重複），按鈕下方會顯示預估間隔。
  • 按 Again 的字會在本回合稍後再出現一次，符合「重複頻率優先」。

2. 鍵盤快捷鍵：

  • 空白鍵 / Enter：翻轉卡片
  • 1 / 2 / 3 / 4：Again / Hard / Good / Easy
  • R：朗讀英文單字
  • Z：揭曉／遮回中文（外語腦模式）

3. 四個練習工具：

  • 跟讀評分：念給瀏覽器聽，機器聽得懂才算過（需 Chrome / Edge 並允許麥克風）。
  • 造句、意象：寫下的內容會存在這台電腦的瀏覽器裡，下次看到同一個字會自動帶出。
  • AI 提示：一鍵複製提示詞，貼到 ChatGPT / Claude 請它批改。

4. 匯入自訂 CSV：

  • 點右上角 ，欄位需含：單字、中文定義、詞性、【詞性變化】、搭配詞、例句、分類、星級、多益分數區間。

5. 為什麼這樣設計？

  • 點右上角 可看「多語學習三大核心策略」心智圖，每條原則都標了對應到介面上的哪個功能。
  • 學習紀錄（間隔重複進度、造句、意象筆記、連續天數）只存在這台電腦的瀏覽器，換裝置或清除瀏覽資料就會消失。
