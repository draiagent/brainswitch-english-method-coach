# 外語腦單字卡 BrainSwitch

> AI 時代的多益互動單字卡 —— 不是把單字表搬上網頁，而是把一套完整的語言學習方法做成可以按的按鈕。

近萬字多益字彙 ｜ 間隔重複排程 ｜ 中文遮罩訓練外語腦 ｜ 語音辨識跟讀評分 ｜ AI 提示詞產生器
**免安裝、免登入、免 API 金鑰，單一 HTML 檔打開就能用。**

---

## 這個工具解決什麼問題

市面上的單字卡多半停在「翻卡 → 看中文 → 下一張」。三個常見後果：

| 常見問題 | 本工具的做法 |
|---|---|
| 按了「不熟」，下一張還是照順序來，等於白按 | 評分**直接決定這個字下次何時再出現**，按鈕上就寫著間隔 |
| 眼睛先掃到中文，大腦從沒真正用英文思考過 | **外語腦模式**把中文模糊化，先用英文理解，點一下才揭曉 |
| 背了單字卻不會用，因為記的是單字不是語塊 | 獨立的**語言積木（chunks）**區，可單獨朗讀、一鍵複製 |
| 「今天讀了 30 分鐘」但不知道到底完成什麼 | 任務以**完成張數**計量，不用時間計量 |

## 功能總覽

### 核心學習迴圈
- **間隔重複排程（SM-2 精簡版）**：Again / Hard / Good / Easy 會更新每個字的熟悉度與到期時間；按鈕下方即時顯示「下次何時再出現」。按 Again 的字會在本回合第 5 張後再出現一次。
- **外語腦模式**：中文釋義、搭配詞中譯、例句翻譯全部模糊化，點擊或按 `Z` 才揭曉。
- **i+1 選材**：以你的分數區間為底，自動混入高一階的單字；同時高星級（高頻字）優先出現。
- **程度設定**：0-400 / 400-600 / 600-780 / 780-900 / 900+ 五個多益分數區間，或全部。

### 每張卡片上有什麼
單字發音、星級與分數區間標籤、分類圖示、中文定義、詞性變化、語言積木（搭配詞）、例句與例句發音。

### 四個實戰練習工具
| 工具 | 做什麼 |
|---|---|
| 🎤 **跟讀評分** | 念給瀏覽器聽，用語音辨識判定「機器聽不聽得懂」。單字必須被完整聽對才算合格 |
| ✍️ **造句** | 用這個字寫一句英文，存在本機，下次遇到同一個字自動帶回 |
| 💡 **意象** | 寫下這個字讓你想到的具體畫面，取代死背中文 |
| 🤖 **AI 提示** | 一鍵複製提示詞貼到 ChatGPT / Claude，請 AI 先優化句子結構再翻譯，並回饋搭配詞 |

### 持續力
🔥 連續學習天數、今日任務進度條、回合完成結算。

## 快速開始

### 線上使用
直接開啟 GitHub Pages 網址即可，不需安裝任何東西。

### 本機使用
因為要讀取 CSV 資料檔，**不能直接用檔案總管雙擊開啟**（瀏覽器的 CORS 限制會擋住讀取）。請起一個本機伺服器：

```bash
python -m http.server 8000
```

然後開啟 `http://localhost:8000`。

> 若真的要離線雙擊使用，也可以打開工具後點右上角 <kbd>⬆</kbd> 手動上傳 `toeic-vocab-data.csv`。

## 設計理念：三大核心策略 × 12 條原則

本工具的每個功能都對應「多語學習三大核心策略」心智圖的一條原則，在工具內點 <kbd>🔗</kbd> 可隨時叫出對照圖（適合課堂投影）。

| 策略 | 原則 | 對應功能 |
|---|---|---|
| **環境營造<br>與心態轉換** | 建立外語腦：強迫切換理解模式 | 外語腦模式（中文遮罩） |
| | 環境推動力：將外語塞進日常流程 | 🔥 連續學習天數 |
| | 內容型學習：以完成任務取代時間量化 | 今日任務以「張數」計 |
| | 接受精神年齡：從簡單的自我溝通開始 | 程度設定（分數區間） |
| **深度理解<br>與高效輸入** | 核心意象：抓住單字背後的具體畫面 | 意象筆記＋分類圖示 |
| | 語言組塊：記憶道地的固定搭配詞 | 語言積木 CHUNKS 區 |
| | 九秒記憶法：重視重複頻率而非單次強度 | 間隔重複排程 |
| | i+1 選材：挑選比當前實力難一點的素材 | i+1 選材開關 |
| **實戰輸出<br>與技術應用** | 寫作即高速口說：鍛鍊表達的精準度 | 造句練習 |
| | 區塊建築原則：直接搬用母語者的積木 | 一鍵複製積木／例句 |
| | AI 預編輯學習：優化結構後再進行翻譯 | AI 提示詞產生器 |
| | 模仿與語音辨識：以機器理解作為合格標準 | 跟讀評分（語音辨識） |

完整說明見 [docs/設計理念.md](docs/設計理念.md)。

## 自訂單字資料

上傳自己的 CSV（右上角 <kbd>⬆</kbd>），欄位如下：

| 欄位 | 必填 | 說明 |
|---|---|---|
| `單字` | ✅ | 英文單字 |
| `中文定義` | | 中文釋義 |
| `詞性` | | 如 noun、verb |
| `【詞性變化】` | | 如 `verb: inform, informs, informing` |
| `搭配詞` | | 一行一組，格式 `英文 中文`，可多行 |
| `例句` | | 第一行英文、第二行中文 |
| `分類` | | 決定卡片的圖示與配色 |
| `星級` | | 1–5，數字越大＝越高頻，優先出現 |
| `多益分數區間` | | `0-400`／`400-600`／`600-780`／`780-900`／`900+`，用於程度篩選與 i+1 選材 |

## 隱私

- 所有學習紀錄（間隔重複進度、造句、意象筆記、連續天數）**只存在你自己瀏覽器的 localStorage**，不會上傳到任何伺服器。
- 本工具沒有後端、沒有帳號、沒有追蹤、不需要任何 API 金鑰。
- 換電腦、換瀏覽器或清除瀏覽資料，紀錄就會消失；同一台電腦的不同使用者紀錄不互通。
- 語音辨識由瀏覽器內建的 Web Speech API 處理，Chrome 會將音訊送至 Google 伺服器辨識——這是瀏覽器本身的行為，介意者請勿使用跟讀評分功能。
