# 外語腦英語方法教練 BrainSwitch

> **把一套完整的語言學習方法，做成學生可以按、老師可以教的工具。**

一個可以帶進教室講解的**語言學習方法論示範品**，順便是一套堪用的日常與商務英語單字卡。

間隔重複排程 ｜ 中文遮罩訓練外語腦 ｜ 語言積木 ｜ 語音辨識跟讀 ｜ AI 提示詞外顯
**打開網址就能用**——免安裝、免註冊、免 API 金鑰、不蒐集任何資料。

建議使用 Chrome 或 Edge（跟讀評分功能需要語音辨識支援）。

## 這個工具解決什麼問題

市面上的單字卡多半停在「翻卡 → 看中文 → 下一張」。三個常見後果：

| 常見問題 | 本工具的做法 |
|---|---|
| 按了「不熟」，下一張還是照順序來，等於白按 | 評分**直接決定這個字下次何時再出現**，按鈕上就寫著間隔 |
| 眼睛先掃到中文，大腦從沒真正用英文思考過 | **外語腦模式**把中文模糊化，先用英文理解，點一下才揭曉 |
| 背了單字卻不會用，因為記的是單字不是語塊 | 獨立的**語言積木（chunks）**區，可單獨朗讀、一鍵複製 |
| 「今天讀了 30 分鐘」但不知道到底完成什麼 | 任務以**完成張數**計量，不用時間計量 |

## 功能總覽

### 核心學習迴圈
- **間隔重複排程（SM-2 精簡版）**：Again / Hard / Good / Easy 會更新每個字的熟悉度與到期時間；按鈕下方即時顯示「下次何時再出現」。按 Again 的字會在本回合第 5 張後再出現一次。
- **外語腦模式**：中文釋義、搭配詞中譯、例句翻譯全部模糊化，點擊或按 `Z` 才揭曉。
- **略高一階選材**：以你的難度等級為底，自動混入高一階的單字；同時高星級（高頻字）優先出現。
- **程度設定**：入門 / 基礎 / 中階 / 進階 / 精熟 五個難度等級，或全部。

### 每張卡片上有什麼
單字發音、星級與難度等級標籤、分類圖示、中文定義、詞性變化、語言積木（搭配詞）、例句與例句發音。

### 四個實戰練習工具
| 工具 | 做什麼 |
|---|---|
| 🎤 **跟讀評分** | 念給瀏覽器聽，用語音辨識判定「機器聽不聽得懂」。單字必須被完整聽對才算合格 |
| ✍️ **造句** | 用這個字寫一句英文，存在本機，下次遇到同一個字自動帶回 |
| 💡 **意象** | 寫下這個字讓你想到的具體畫面，取代死背中文 |
| 🤖 **AI 提示** | 一鍵複製提示詞貼到 ChatGPT / Claude，請 AI 先優化句子結構再翻譯，並回饋搭配詞 |

### 持續力
🔥 連續學習天數、今日任務進度條、回合完成結算。

### 單字資料
收錄 9,782 個日常與商務高頻英語單字，含中文定義、詞性變化、搭配詞、例句、情境分類、星級（常用度）與難度等級。

> 字數不是本工具的賣點。**真正影響成效的是複習排程與輸出練習，不是題庫大小**——所以介面用「難度等級 + 星級排序 + 略高一階選材」把你每天實際會碰到的字收斂到二十來張，而不是讓你面對一萬字的清單。

## 快速開始

### 線上使用
直接開啟 **<https://draiagent.github.io/brainswitch-english-method-coach/>**，不需安裝任何東西，開啟即可使用。

### 本機使用
因為要讀取 CSV 資料檔，**不能直接用檔案總管雙擊開啟**（瀏覽器的 CORS 限制會擋住讀取）。請起一個本機伺服器：

```bash
python -m http.server 8000
```

然後開啟 `http://localhost:8000`。

> 若真的要離線雙擊使用，也可以打開工具後點右上角 <kbd>⬆</kbd> 手動上傳 `vocab-data.csv`。

## 設計理念：三大面向 × 12 條做法

本工具的每個功能都對應「語言學習方法架構」心智圖的一條原則，在工具內點 <kbd>🔗</kbd> 可隨時叫出對照圖（適合課堂投影）。

| 面向 | 做法 | 對應功能 |
|---|---|---|
| **環境<br>與心態** | 先用外語想：不讓母語搶先出現 | 外語腦模式（中文遮罩） |
| | 嵌入日常：讓接觸外語變成固定行程 | 🔥 連續學習天數 |
| | 以完成量計進度：不用時間計量 | 今日任務以「張數」計 |
| | 從說得出口的程度起步：先求能表達 | 程度設定（難度等級） |
| **理解<br>與輸入** | 記畫面不記字：為每個字抓一個場景 | 意象筆記＋分類圖示 |
| | 整組記固定語塊：搭配詞一起背 | 語言積木 CHUNKS 區 |
| | 短間隔多次複習：次數重於單次時長 | 間隔重複排程 |
| | 選略高一階的素材：全懂就不會進步 | 略高一階選材開關 |
| **輸出<br>與工具** | 寫得出來才說得出來：用寫作練精準度 | 造句練習 |
| | 借用母語者的句型：沿用現成結構 | 一鍵複製積木／例句 |
| | 請 AI 先重整再翻譯：要它指出結構問題 | AI 提示詞產生器 |
| | 讓機器當發音裁判：機器聽懂才算過 | 跟讀評分（語音辨識） |

完整說明見 [docs/設計理念.md](docs/設計理念.md)。

## 隱私

- 所有學習紀錄（間隔重複進度、造句、意象筆記、連續天數）**只存在你自己瀏覽器的 localStorage**，不會上傳到任何伺服器。
- 本工具沒有後端、沒有帳號、沒有追蹤、不需要任何 API 金鑰。
- 換電腦、換瀏覽器或清除瀏覽資料，紀錄就會消失；同一台電腦的不同使用者紀錄不互通。
- 語音辨識由瀏覽器內建的 Web Speech API 處理，Chrome 會將音訊送至 Google 伺服器辨識——這是瀏覽器本身的行為，介意者請勿使用跟讀評分功能。

## 本專案如何用 AI 生成

這個專案本身就是一份**生成式 AI 協作開發的公開教材**：從一張心智圖截圖開始，全程由人與 AI（Claude Code）對話完成，包含程式、資料處理、文件與競品研究。

完整過程如下，刻意記錄下來供教學參考。

### 起點是一張圖，不是一份規格書
輸入只有一張「語言學習方法架構」的心智圖截圖，以及一句要求：**把這 12 條原則做成可以按的功能，不要只是把圖貼上去**。

AI 逐條把抽象概念翻譯成介面元素——例如「短間隔多次複習」對應到「Again 的字在本回合第 5 張後重新出現」、「讓機器當發音裁判」對應到語音辨識判定。對照表見 [設計理念](docs/設計理念.md)。

### AI 實際做了哪些事
| 工作 | 說明 |
|---|---|
| 資料處理 | 撰寫並執行 Python 腳本轉換 9,782 筆資料、重新命名欄位與值 |
| 程式實作 | 間隔重複演算法、語音辨識評分、localStorage 遷移邏輯 |
| 瀏覽器實測 | 以自動化操作實際翻卡、評分、切換難度，驗證每項功能並讀取 console 錯誤 |
| 競品研究 | 網路搜尋比對 Anki／Quizlet／ELSA 等競品，產出 [競品分析](docs/競品分析.md) |
| 授權查證 | 查出資料集為 CC BY-SA 4.0，據此拆分程式碼與資料的授權 |

### 三個值得拿來教的片段

**1. AI 抓到自己的設計瑕疵。**
跟讀評分初版用字串相似度判定，測試時發現 `agility` 對 `ability` 相似度達 86%，會誤判為「發音合格」。既然原則是「機器聽懂才算過」，聽成別的字就不該算過——因此改為單字必須被完整聽對。**能被自動測試抓到的瑕疵，才是真的被修掉的瑕疵。**

**2. 查證勝過直覺。**
原本預設「資料集大概可以自由使用」，實際查證後發現是 CC BY-SA 4.0（具傳染性、需標示出處），才據此建立 [DATA-LICENSE.md](DATA-LICENSE.md)。**AI 協作最大的風險不是寫錯程式，是沒有去查。**

**3. 誠實的競品分析比自我宣傳有用。**
競品研究的結論是「我們每一項功能都有人做得更好」，於是定位從功能競賽改成方法論教學。這份分析原封不動放進 repo，包含所有劣勢。

### 這代表 AI 可以取代開發者嗎？
不代表。全程由人決定的包括：產品命名、要不要獨立成 repo、資料授權怎麼處理、去除檢定名稱綁定、以及最終定位。**AI 負責執行與查證，方向仍然是人給的。**

工具內的 🤖 AI 提示分頁也是同一個理念：不把 AI 藏在按鈕後面，而是讓提示詞攤開來給學習者看——順便教怎麼問 AI。
